iPhone Safari has no fullscreen API. For an edge-to-edge, chrome-free visualizer, use Share → Add to Home Screen and launch it from the icon.

Keyboard: H panel · F fullscreen · R random mode · C clear · Space play/pause · ← → change mode

Touch: tap the edge handle to slide the panel away, or swipe left / right anywhere on the visualizer. Swipe up / down to change mode.

WebGL 2.0 unavailable

The fluid modes need WebGL 2.0 with EXT_color_buffer_float. The 2D modes will still work — pick one from the Visualizer list.
